# Roadmap

## Curto prazo

- melhorar observabilidade de erros em Android e web
- polir mais a UX da web e do app Android
- refinar o PTT em cenarios com reconexao
- documentar deploy do servidor

## Medio prazo

- colocar o servidor de sinalizacao em um ambiente publico
- servir a web por HTTPS por padrao
- gerar build release assinada do Android
- melhorar a experiencia no iPhone

## Longo prazo

- estudar migracao de host
- avaliar persistencia de salas e eventos
- considerar autenticacao leve
- avaliar criptografia ponta a ponta
